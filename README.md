# Valorant Takeover

**gta5** × Valorant · visual · idea by the team

Bring Valorant into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned the GTA V runway into a Valorant match: agents, abilities, and a Spike that falls from the sky and blows up the airfield.

## Install

Put this folder in your FiveM server's resources folder as sigf_mod, add "ensure sigf_mod" to server.cfg, and join. Rounds start by themselves. Press Q for flames, E for smoke, C for a barrier and X for an updraft.
